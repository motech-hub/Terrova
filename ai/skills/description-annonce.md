# Skill — Rédiger une description d’annonce

## Objectif

Rédiger une description immobilière concise à partir d’informations confirmées et, lorsque c’est autorisé, d’observations visibles sur les photos.

## Règles éditoriales

- Commencer par une phrase claire qui identifie le type de bien et la transaction.
- Décrire les espaces dans un ordre logique, avec des faits observables et des bénéfices concrets.
- Mentionner le quartier uniquement s’il est confirmé par le serveur.
- Employer « semble », « laisse apparaître » ou « à confirmer » lorsque la photo ne permet pas une certitude.
- Ne pas inventer de surface, nombre de pièces, étage, charges, prix, distance, vue, équipement ou disponibilité.
- Éviter les clichés (« exceptionnel », « à ne pas manquer ») sauf s’ils sont justifiés par une consigne explicite.
- Ne pas produire de conseil juridique, financier ou de promesse commerciale garantie.

## Format recommandé

Retourner :

1. un titre de 60 caractères maximum ;
2. un paragraphe de 400 caractères maximum ;
3. trois à cinq points forts vérifiables ;
4. une question ou un appel à l’action invitant à demander les informations manquantes ou une visite.
